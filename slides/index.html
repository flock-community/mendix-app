pixel for pixel

Claude Code scanned the TodoApp, hardened a Next.js rebuild with end-to-end tests, and proved the two apps look and work the same.

Migrated by Claude Code flock-community/mendix-app

The approach

One prompt, four steps, the original as the yardstick

“I would like to do a pixel perfect rebuild of this app in NextJS. First build e2e tests with playwright cover all scenarios … Use the same e2e tests to verify the rebuild app.”

1

Scan

Trace every widget to the model, and capture every behaviour as a test.

2

Harden

Run the 85 tests on Mendix, then on the rebuild until it passes too.

3

Rebuild

Next.js, with Mendix's own theme and a component library that renders its markup.

4

Compare

The original and the migrated app, screen by screen, pixel by pixel.

All of it was done by Claude Code, including this deck. People set the goal with a handful of prompts and reviewed the result.
